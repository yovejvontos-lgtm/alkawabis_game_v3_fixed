# الكوابيس — الإصدار 2 (Alkawabis v2)

لعبة قتال 2D جانبية، حتى **6 لاعبين** عبر الواي فاي. مبنية بـ Flutter.

- **الحزمة:** `com.alkawabis.game`  •  **التطبيق:** الكوابيس  •  **الإصدار:** 2.0.0+2
- **الأيقونة وصورة الغلاف:** من صورة اللعبة (`mipmap-*` و`assets/cover.png`)

## الجديد في الإصدار 2
1. **كومبو اللكم والركل:** 3 لكمات مختلفة (مستقيمة، بالذراع الخلفية، صاعدة) و3 ركلات (أمامية، دائرية، طائرة). اضغط الزر عدة مرات متتالية.
2. **تقدّم الشخصية عند الضرب:** اندفاع للأمام ومدى أبعد للهجوم.
3. **صحة اللاعب الضعف:** نحو 14 ضربة بدل 7.
4. **المراحل مقفلة:** تبدأ بالأولى، وكل فوز يفتح التالية (تُحفظ).
5. **سلاسة أقوى:** عرض مُنعَّم بين خطوات الفيزياء، وانتقال ناعم بين الحركات، وتنعيم وتوقّع للحركة عند اللاعبين الضيوف.
6. **اسم الشخصية** يظهر فوق رأسها وفي شريط الصحة (شاشة «شخصيتي»).
7. **الأزياء:** 10 علوية و10 سفلية و5 كاملة مستوحاة، مع ألوان ومعاينة متحركة. يبقى الرأس أسود بالكامل. (تُحفظ)
8. **حتى 6 لاعبين:** تعاون ضد الأعداء، مواجهة حرة، أو فرق (3 ضد 3) مع غرفة انتظار بالأسماء والأزياء.

## اللعب الجماعي
1. أحد اللاعبين يفتح نقطة اتصال (Hotspot) والبقية يتصلون بها.
2. المضيف: لعب جماعي ← إنشاء حفلة، فيظهر عنوان IP.
3. البقية: لعب جماعي ← الانضمام لحفلة، ويكتبون العنوان.
4. المضيف يختار الوضع والمرحلة (وفي الفرق يضغط على فريق اللاعب لتبديله) ثم «ابدأ اللعبة».

المنفذ: `45678` (TCP). المضيف يشغّل المحاكاة كاملة ويبث اللقطات للجميع، فيفضّل أن يكون هاتفه الأقوى.
